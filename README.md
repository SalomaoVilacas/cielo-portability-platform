# Cielo Portability Platform

Full-stack technical challenge implementing a payroll deduction agreement portability platform.

## Tech Stack

- Java 21
- Spring Boot 4.1.2
- Maven
- React + TypeScript (planned)
- H2 Database
- GitHub Actions (planned)

## Modules

- `backend`: Portability REST API.
- `central-mock`: External agreement center simulator.
- `frontend`: React application (to be implemented).

## Project Status

Initial project setup.

Architecture, integration contracts, test scenarios and execution instructions will be documented as implementation progresses.
